# 流動的雙北

**公車、捷運與日常可達性的時空研究**

[探索互動網站](https://hardy1yang.github.io/taipei-bus/) · [閱讀研究專書](https://hardy1yang.github.io/taipei-bus/book.html) · [下載 PDF](https://hardy1yang.github.io/taipei-bus/book.pdf)

本研究整合雙北 41 個行政區、1,051 條公車路線的 2,568 筆去回程與支線紀錄，分析路線相似性、住宅到站距離及軌道鄰近關係。

地圖提供區里界、道路、水系、地形、人口估計與步行距離；路線選取與降維圖聯動，可依長度、捷運鄰近比例和主要延伸方向比較。六個案例將空間差異連到住宅入口、過街、河川阻隔與軌道接駁的規劃問題。

## 主要發現

- 幾何 UMAP 的局部保真度為 0.9966，但沒有全域地理方向通過驗證條件；相似性宜用於局部路線分工比較。
- 路線長度與已收錄捷運入口鄰近比例的 Spearman 相關為 −0.065；路線長短不足以概括其軌道關係。
- 南港案例的網格代表點到站約 780 公尺，住宅取樣平均為 81 公尺；新店的平均為 185 公尺、第 90 百分位為 511 公尺。住宅位置與格內差異會影響改善對象的辨識。

研究採空間描述與條件式情境。戶籍人口為 2024-12、活動人口為 2020-11、捷運 OD 為 2026-07。當期班次、完整旅程時間及部分軌道入口仍未完整涵蓋，因此不提供實測全程時間或投資報酬排名。
